Building Stages
---------------

1.Scan common IoT TCP ports.

2.Identify likely services such as MQTT and Telnet.

3.Map MAC addresses to manufacturers using a local IEEE registry.

4.Audit default-credential security on devices you own or are authorized to test.

5.Generate a security report.

SEPARATION OF CONCERNS
------------------------------------------------------------------------------------------------------------------------

* IoTScanner
* MAC Discovery
* MAC LookUp
* Credential Audit
* Security Report

------------------------------------------------------------------------------------------------------------------------
LIMITATIONS

The target normally needs to be on the same local network segment as your computer.

A missing ARP entry does not prove the device is offline.

This implementation is Windows-specific; Linux uses different command options.

If a MAC address cannot be discovered, don't label the manufacturer as confirmed. Report it as unavailable instead.

Test parsing and manufacturer lookup separately from the real network discovery, so your unit tests don't depend on a live device.

For offline Devices The Scanner Uses The CSV database to search for the MAC address.
Online Devices Uses the API to search for the MACAddress. API returns a JSON response which gets deserielized into a String object
and will be added the Scan Report
